# Releases 341–350 roadmap

    | Release | Capability | Intended outcome |
    |---:|---|---|
    | 341 | Data Contract Registry v2 | Version data schemas, quality objectives, owners, compatibility, retention and consumer obligations. |
| 342 | Semantic Layer and Metric Governance | Govern business metrics, dimensions, calculations, owners, lineage and change control. |
| 343 | Privacy-Enhancing Technology Catalogue | Register approved privacy-enhancing patterns, assumptions, limitations and qualified reviewers. |
| 344 | Differential Privacy Budget Management | Allocate privacy budgets, queries, composition limits, approvals and exhaustion controls. |
| 345 | Federated Analytics Governance | Coordinate local computation, approved aggregations, participant controls and output review. |
| 346 | Secure Multi-Party Computation Readiness | Assess protocols, participants, threat assumptions, performance, key management and fallback. |
| 347 | Homomorphic Encryption Readiness | Assess supported computations, parameter safety, performance, key custody and operational limits. |
| 348 | Synthetic Data Quality and Disclosure | Evaluate privacy, fidelity, bias, utility, provenance and synthetic-data disclosure. |
| 349 | Responsible Data Value and Sharing Readiness | Evaluate governed data value, purpose, contracts, access, portability and public-interest risk. |
| 350 | Data Intelligence Assurance Gate | Gate advanced data capability on contracts, privacy, methodology, quality, sharing and recovery evidence. |
