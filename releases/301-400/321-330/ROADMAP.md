# Releases 321–330 roadmap

    | Release | Capability | Intended outcome |
    |---:|---|---|
    | 321 | Cryptographic Asset Inventory | Inventory algorithms, keys, certificates, protocols, owners, expiry and dependency exposure. |
| 322 | Key and Certificate Lifecycle Automation | Automate approved issuance, renewal, rotation and revocation with receipts and emergency stops. |
| 323 | Post-Quantum Cryptography Readiness | Assess algorithm exposure, protocol dependencies, migration options, interoperability and risk. |
| 324 | Confidential Computing Readiness | Govern trusted-execution workloads, attestation, key release, data boundaries and fallback. |
| 325 | Secure Enclave Workload Governance | Control enclave identity, measurements, secrets, debug state, updates and incident response. |
| 326 | Zero-Trust Service Mesh | Apply workload identity, mutual authentication, authorisation, telemetry and policy enforcement. |
| 327 | Workload Identity and SPIFFE Readiness | Define workload identities, trust domains, issuance, rotation and federation readiness. |
| 328 | Security Policy Verification and Model Checking | Validate security policies for conflicts, unreachable rules, unsafe defaults and bypass paths. |
| 329 | Cryptographic Incident Response | Coordinate compromise containment, revocation, rotation, rebuild and evidence preservation. |
| 330 | Cryptographic Agility Assurance Gate | Gate cryptographic readiness on inventory, lifecycle, migration, attestation and incident evidence. |
