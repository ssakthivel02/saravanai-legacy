# Releases 311–320 roadmap

    | Release | Capability | Intended outcome |
    |---:|---|---|
    | 311 | Agent Specification and Capability Contracts | Define agent goals, permissions, inputs, outputs, limitations, owners and lifecycle contracts. |
| 312 | Agent Planning and Goal Governance | Govern plans, dependencies, constraints, deadlines, replanning and human approval. |
| 313 | Agent Tool Permission Compiler | Compile least-privilege tool capabilities, egress rules and approval requirements into runtime policy. |
| 314 | Agent Communication Protocols | Version agent-to-agent message contracts, correlation, authentication, replay protection and timeouts. |
| 315 | Multi-Agent Coordination and Deadlock Control | Coordinate agent roles, locks, priorities, cancellation and deadlock recovery. |
| 316 | Formal Invariant and Constraint Verification | Verify safety invariants, forbidden states, resource bounds and policy constraints before execution. |
| 317 | Agent Test Harness and Scenario Replay | Run deterministic scenarios, fault injection, tool stubs, golden outcomes and replay evidence. |
| 318 | Agent Behaviour Drift Monitoring | Detect changes in tool use, policy adherence, outcomes, cost and human escalation patterns. |
| 319 | Human Oversight and Override Operations | Provide pause, cancel, redirect, approve, appeal and evidence-preserving human controls. |
| 320 | Agent Engineering Assurance Gate | Gate agent release on specification, permission, verification, testing, drift and oversight evidence. |
