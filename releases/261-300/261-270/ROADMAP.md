# Releases 261–270 roadmap

    | Release | Capability | Intended outcome |
    |---:|---|---|
    | 261 | Enterprise Process Catalogue | Register business processes, owners, criticality, dependencies, data classes and lifecycle state. |
| 262 | Workflow Definition and Versioning | Version workflow steps, conditions, retries, timeouts, compensation and publication approvals. |
| 263 | Decision Tables and Rules Management | Govern deterministic decisions through versioned rules, effective dates, tests, conflicts and approvals. |
| 264 | Human Task and Approval Orchestration | Coordinate assignments, separation of duties, deadlines, delegation, evidence and escalation. |
| 265 | Document-Driven Process Automation | Extract and route document information through validation, provenance, classification and human review. |
| 266 | Communication Automation Governance | Automate email, calendar and collaboration actions with consent, recipient checks, templates and send approval. |
| 267 | Robotic Process Automation Safety | Control desktop and browser automation through allowlists, dry-run, idempotency, bounded steps and kill switches. |
| 268 | Process Mining and Conformance | Analyse event traces for bottlenecks, deviations and control failures without invasive worker surveillance. |
| 269 | Automation Value and Performance | Measure cycle time, quality, error reduction, human effort, cost and customer outcomes with evidence. |
| 270 | Enterprise Automation Assurance Gate | Gate automation on process, workflow, approvals, document, communication, RPA, conformance and value evidence. |
