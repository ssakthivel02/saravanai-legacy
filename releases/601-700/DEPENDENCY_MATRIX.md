# Dependency matrix

- Runtime control depends on model governance, safety, privacy, capacity and free-first budgets.
- Agent operations depend on identity, tool manifests, sandboxing and checkpoints.
- Retrieval depends on source governance, access filters, citations and freshness.
- Sovereignty depends on residency, purpose, rights, classification and deletion.
- Multimodal operations depend on consent, rights, provenance and accessibility.
- Developer execution depends on workspace isolation, dependencies, builds and tests.
- SRE depends on telemetry, SLOs, incident command and safe remediation.
- Workflow automation depends on process ownership, rules, connectors and exceptions.
- Assurance depends on obligations, evidence, findings and independent review.
- Enterprise v6 completion depends on evidence from all preceding domains.

No pack bypasses controls introduced by Releases 021–600.
