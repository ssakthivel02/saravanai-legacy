# Releases 581–590 roadmap

    | Release | Capability | Intended outcome |
    |---:|---|---|
    | 581 | Locale and Market Readiness Registry | Register locales, scripts, formats, regulations, owners, evidence and release state. |
| 582 | Translation Quality and Terminology v3 | Govern terminology, translation memory, quality sampling, native review and corrections. |
| 583 | Bidirectional and Complex Script Support | Validate bidirectional text, shaping, line breaking, fonts, input and export behaviour. |
| 584 | Accessible Design System v2 | Govern components, semantics, keyboard, contrast, motion, alternatives and versioning. |
| 585 | Cognitive Accessibility and Plain Language | Apply readable structure, plain language, error prevention, help and alternative journeys. |
| 586 | Inclusive Personalisation and User Controls | Provide user-controlled presentation, language, accessibility and personalisation with opt-out. |
| 587 | Cultural and Religious Sensitivity Operations v3 | Apply respectful classification, source review, community input, correction and escalation. |
| 588 | Regional Legal and Content Review | Coordinate jurisdiction, qualified review, restrictions, records, appeals and release decisions. |
| 589 | Global Experience Quality Analytics | Measure locale, accessibility, content, support and journey quality without invasive profiling. |
| 590 | Global Experience Assurance Gate | Gate global release on locale, translation, scripts, accessibility, culture and legal evidence. |
