# Threat model

Threats include account takeover, tenant escape, confused deputy, prompt injection,
secret exfiltration, unsafe multimodal content, poisoned evidence, model misuse,
unauthorised automation, supplier compromise, privacy violations, vulnerable-user harm,
telemetry leakage and unapproved production release.

Controls include verified identity, tenant predicates, least privilege, four-eyes approval,
content and output safety gates, provenance, checksums, safe telemetry, restore evidence,
protected branches and explicit owner go/no-go decisions.
