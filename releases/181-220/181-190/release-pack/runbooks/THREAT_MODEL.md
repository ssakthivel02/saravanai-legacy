# Threat model

Threats include tenant escape, prompt injection, poisoned retrieval, memory leakage,
unsafe tools, schema abuse, data exfiltration, supply-chain compromise, identity theft,
fraudulent accounts, evidence tampering and irreversible production changes.

Controls use trusted identity, default deny, four-eyes approval, bounded execution,
egress allowlists, integrity hashes, safe telemetry, protected branches and rollback.
