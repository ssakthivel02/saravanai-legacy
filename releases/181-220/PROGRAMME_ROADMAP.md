# Releases 181–220 programme roadmap

| Release | Capability | Intended outcome |
|---:|---|---|
| 181 | AI Runtime Control Plane | Control model, agent, tool and retrieval execution through trusted identity, policy, budgets, approvals and runtime kill switches. |
| 182 | Prompt and Policy Lifecycle | Version prompts and policy instructions with provenance, tests, approvals, effective dates, rollback and secret-leak prevention. |
| 183 | Model Evaluation and Benchmark Registry | Register benchmark suites, datasets, safety thresholds, model results, regressions and promotion decisions. |
| 184 | Retrieval and Corpus Operations | Operate corpora through ingestion, access control, freshness, lineage, re-indexing, deletion and retrieval evaluation. |
| 185 | Agent Memory Operations | Govern working, project and organisational memory through consent, confidence, expiry, correction, deletion and isolation. |
| 186 | Tool and Connector Runtime Governance | Execute tools and connectors only through capability allowlists, egress rules, credential bindings, idempotency and receipts. |
| 187 | AI Safety Incident and Abuse Investigation | Investigate prompt injection, harmful output, policy bypass, secret leakage and tool misuse with evidence-preserving case handling. |
| 188 | AI Cost and Performance Optimisation | Optimise latency, quality and free-first resource use while enforcing hard budgets and preventing silent paid-provider activation. |
| 189 | AI Change and Rollback Management | Govern model, prompt, policy, corpus and agent changes through impact review, canaries, evidence, rollback and change windows. |
| 190 | AI Production Intelligence Assurance Gate | Gate AI production capability on evaluation, safety, retrieval, memory, tool, cost, change and recovery evidence. |
| 191 | Enterprise Data Mesh Governance | Define data domains, products, owners, contracts, quality objectives, access policies and federated governance. |
| 192 | Master and Reference Data Management | Manage golden records, identifiers, survivorship, stewardship, reference values, history and conflict resolution. |
| 193 | Event Streaming and Schema Registry | Govern domain events through schemas, compatibility, tenant context, replay, retention, dead-letter and consumer contracts. |
| 194 | Enterprise Integration Orchestration | Coordinate APIs, events and batch integration with correlation, retries, compensation, approvals and dependency controls. |
| 195 | Data Quality Observability | Measure completeness, validity, uniqueness, freshness, lineage and access-control quality with accountable remediation. |
| 196 | Privacy-Preserving Analytics | Provide aggregated analytics with minimisation, purpose limitation, suppression, access control and re-identification safeguards. |
| 197 | Secure Data Sharing and Clean-Room Readiness | Govern controlled data collaboration through purpose, contracts, field allowlists, query restrictions, output review and expiry. |
| 198 | Records Discovery and eDiscovery Readiness | Locate, preserve, review and export records through legal holds, chain of custody, access controls and defensible audit trails. |
| 199 | Data Product Lifecycle and Contracting | Manage data products from proposal through operation, versioning, deprecation, portability and retirement. |
| 200 | Data and Integration Assurance Gate | Gate enterprise data capability on contracts, quality, privacy, sharing, records, integration and recovery evidence. |
| 201 | Geopolitical and Regional Risk Intelligence | Track regional dependencies, sanctions-screening boundaries, service exposure, local review and continuity implications. |
| 202 | Crisis Information Integrity | Publish emergency and crisis information only with source verification, timestamps, corrections, authority and escalation. |
| 203 | Vulnerability and Patch Governance | Manage vulnerabilities, affected assets, exploitability, remediation SLAs, exceptions, patch evidence and compensating controls. |
| 204 | Software Supply-Chain Provenance | Require dependency inventory, SBOM, signatures, build provenance, vulnerability review and revocation capability. |
| 205 | Identity Threat Detection and Response | Detect suspicious authentication, impossible travel, session theft, privilege escalation and service-account misuse. |
| 206 | Privileged and Insider Risk Controls | Govern privileged activity through just-in-time access, four-eyes approval, session evidence, separation and revocation. |
| 207 | Fraud Account Abuse and Misuse Prevention | Detect account farming, credential abuse, automation misuse, quota evasion and fraudulent workflows with appeal paths. |
| 208 | Cyber Recovery and Resilience Operations | Coordinate immutable backup, restore, isolated recovery, dependency validation, communications and return-to-service evidence. |
| 209 | Transparency Reporting and Redress | Publish explainable trust metrics, incident summaries, policy changes, complaint handling and correction mechanisms. |
| 210 | Global Trust and Resilience Assurance Gate | Gate global operation on regional risk, crisis integrity, vulnerabilities, supply chain, identity, abuse and recovery evidence. |
| 211 | Enterprise Strategy and Objectives | Translate enterprise objectives into measurable outcomes, owners, dependencies, risks and evidence-linked initiatives. |
| 212 | Architecture Portfolio and Technology Radar | Manage standards, approved technologies, trials, exceptions, lifecycle stages and architectural decision evidence. |
| 213 | Scenario Intelligence and Forecasting | Develop evidence-based scenarios with assumptions, confidence, triggers, alternatives and human-reviewed decisions. |
| 214 | Board Decision and Accountability Records | Record material decisions, alternatives, conflicts, approvals, evidence, residual risks and review dates. |
| 215 | Innovation Portfolio Governance | Manage innovation hypotheses, experiments, funding boundaries, ethical review, evidence and stop or scale decisions. |
| 216 | Workforce and Skills Intelligence | Map role capabilities, skills, learning plans, succession risks and workforce decisions without invasive worker surveillance. |
| 217 | Technology and Supplier Evaluation | Evaluate products and suppliers through requirements, security, privacy, portability, cost and exit evidence. |
| 218 | Capacity Sustainability and Demand Planning | Forecast demand, capacity, service limits, energy estimates, performance and scale actions with uncertainty. |
| 219 | Archive Exit and Long-Term Preservation | Preserve essential records, formats, checksums, metadata, access controls and disposal evidence through programme exit. |
| 220 | Enterprise Intelligence Completion Gate | Close Releases 181–220 only after AI operations, data integration, global trust and strategic assurance evidence is approved. |
