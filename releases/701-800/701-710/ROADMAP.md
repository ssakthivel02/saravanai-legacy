# Releases 701–710 roadmap

    | Release | Capability | Intended outcome |
    |---:|---|---|
    | 701 | AI Evaluation Dataset Registry | Register approved evaluation datasets, licences, owners, domains, sensitivity, versions and limitations. |
| 702 | Model Capability Benchmark Framework | Benchmark reasoning, retrieval, coding, multilingual, multimodal and tool-use capabilities with reproducible evidence. |
| 703 | Safety Evaluation and Harm Taxonomy | Evaluate safety behaviour across defined harm categories, contexts, languages and affected groups. |
| 704 | Prompt Injection and Tool Abuse Testing | Test direct and indirect injection, tool escalation, data exfiltration and policy bypass scenarios. |
| 705 | Hallucination and Factuality Evaluation v2 | Measure unsupported claims, source use, temporal accuracy, uncertainty and correction behaviour. |
| 706 | Fairness and Accessibility Evaluation | Evaluate relevant group impacts, language performance, assistive technology compatibility and alternative journeys. |
| 707 | Adversarial Red Team Campaign Management | Plan scoped red-team campaigns, testers, rules, evidence, findings, remediation and disclosure. |
| 708 | Model Regression and Release Comparison | Compare model and prompt versions against protected baselines, tolerances and critical failure tests. |
| 709 | Evaluation Evidence and Decision Dashboard | Present traceable quality, safety, cost, latency, failures, caveats and release decisions. |
| 710 | AI Evaluation and Red Team Assurance Gate | Gate AI releases on dataset, benchmark, safety, injection, factuality, fairness and remediation evidence. |
