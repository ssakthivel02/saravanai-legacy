# Releases 761–770 roadmap

    | Release | Capability | Intended outcome |
    |---:|---|---|
    | 761 | Hybrid Infrastructure Service Catalogue | Register cloud, datacentre, network, compute, storage and platform services with owners and SLOs. |
| 762 | Landing Zone and Account Subscription Factory | Provision governed accounts, subscriptions, projects, policies, logging, budgets and network boundaries. |
| 763 | Infrastructure as Code Module Registry | Govern reusable modules, versions, provenance, tests, security, documentation and deprecation. |
| 764 | Server and Workload Modernisation Assessment | Assess workloads for retain, rehost, replatform, refactor, replace or retire decisions. |
| 765 | Hybrid Connectivity and Network Automation | Govern routing, DNS, firewall, private access, certificates, monitoring and rollback. |
| 766 | Compute Cluster and Virtualisation Operations | Manage clusters, hosts, capacity, maintenance, migrations, compatibility and recovery. |
| 767 | Storage Data Protection and Recovery | Govern storage tiers, encryption, replication, backup, restore, integrity and lifecycle. |
| 768 | Cloud Security Posture and Configuration Drift | Assess policies, identities, exposure, encryption, logging, drift and remediation evidence. |
| 769 | Infrastructure Change and Migration Orchestration | Rehearse and coordinate infrastructure changes, cutovers, validation, rollback and communications. |
| 770 | Hybrid Cloud and Infrastructure Assurance Gate | Gate infrastructure on landing zones, IaC, networking, compute, storage, security and migration. |
