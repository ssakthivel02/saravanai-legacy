# Releases 741–750 roadmap

    | Release | Capability | Intended outcome |
    |---:|---|---|
    | 741 | Learning Programme and Curriculum Registry | Register programmes, outcomes, prerequisites, audience, owners, sources, versions and review dates. |
| 742 | Personal Learning Path and Study Plan | Create learner-controlled plans using goals, baseline, availability, accessibility and progress evidence. |
| 743 | Interactive Lesson and Practice Generator | Generate grounded lessons, examples, quizzes and practice with source and difficulty controls. |
| 744 | Assessment Question Bank and Integrity | Govern questions, answers, explanations, difficulty, coverage, fairness, security and retirement. |
| 745 | Learning Progress and Mastery Evidence | Measure progress, mastery, gaps, confidence and recommended review without invasive surveillance. |
| 746 | Career Profile Resume and Portfolio Composer | Compose evidence-backed resumes, profiles and portfolios with user control and no fabricated claims. |
| 747 | Interview Simulation and Feedback | Run role-based interview practice with transparent scoring, examples, limitations and learner control. |
| 748 | Skills Taxonomy and Role Mapping | Map skills to roles, levels, evidence, learning resources, market context and review dates. |
| 749 | Training Accessibility and Multilingual Delivery | Provide captions, transcripts, readable formats, localisation, assistive support and alternatives. |
| 750 | Learning and Career Services Assurance Gate | Gate learning services on sources, integrity, fairness, privacy, accessibility and correction. |
