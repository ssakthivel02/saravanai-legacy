# Releases 751–760 roadmap

    | Release | Capability | Intended outcome |
    |---:|---|---|
    | 751 | Industrial Asset and Site Registry | Register sites, assets, owners, criticality, networks, firmware, support and lifecycle. |
| 752 | OT Network Zone and Conduit Model | Model zones, conduits, protocols, trust, monitoring, dependencies and approved communications. |
| 753 | Industrial Edge Workload Governance | Govern edge applications, resources, identities, data flows, updates, fallback and local autonomy. |
| 754 | IoT Device Identity and Lifecycle | Issue device identity, enrolment, attestation, configuration, rotation, quarantine and retirement. |
| 755 | Sensor Data Quality and Minimisation | Validate sensor accuracy, context, quality, purpose, retention, privacy and anomaly handling. |
| 756 | OT Vulnerability and Patch Readiness | Assess advisories, exposure, compatibility, safety, maintenance windows, rollback and exceptions. |
| 757 | Industrial Change and Maintenance Control | Govern changes through permits, dependencies, safety review, windows, tests, rollback and evidence. |
| 758 | OT Security Monitoring and Incident Response | Monitor industrial signals, triage safely, preserve evidence, contain and recover with operations. |
| 759 | Industrial Continuity and Manual Fallback | Maintain safe manual operation, spares, communications, recovery tiers and exercised procedures. |
| 760 | OT Edge and IoT Assurance Gate | Gate industrial services on assets, zones, identity, data, patching, incidents and continuity. |
