# Releases 771–780 roadmap

    | Release | Capability | Intended outcome |
    |---:|---|---|
    | 771 | Enterprise Data Product Registry | Register data products, owners, consumers, contracts, quality, sensitivity, SLOs and lifecycle. |
| 772 | Data Contract and Schema Evolution | Version schemas, semantics, compatibility, quality, lineage, consumers and deprecation. |
| 773 | Master and Reference Data Governance | Govern golden records, identifiers, survivorship, stewardship, quality and distribution. |
| 774 | Enterprise Semantic and Metrics Layer | Define governed concepts, measures, dimensions, calculations, ownership and versioning. |
| 775 | Data Product Access and Usage Control | Enforce identity, purpose, tenant, row, field, region, retention and usage restrictions. |
| 776 | Data Quality Rules and Observability | Monitor completeness, validity, timeliness, uniqueness, consistency, drift and ownership. |
| 777 | Data Lineage Impact and Change Analysis | Trace source-to-consumer lineage, changes, dependencies, risk, approvals and communications. |
| 778 | Data Product Marketplace and Discovery | Provide approved discovery, documentation, samples, access requests and consumer feedback. |
| 779 | Data Product Deprecation and Portability | Plan migration, export, consumer transition, archive, deletion and evidence. |
| 780 | Data Products and Semantic Layer Assurance Gate | Gate data products on contracts, master data, semantics, access, quality, lineage and portability. |
