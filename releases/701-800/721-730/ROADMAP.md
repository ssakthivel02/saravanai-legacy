# Releases 721–730 roadmap

    | Release | Capability | Intended outcome |
    |---:|---|---|
    | 721 | Application Product Brief and Requirements | Define users, outcomes, journeys, constraints, data, security, accessibility and success measures. |
| 722 | Experience Architecture and Design System | Govern information architecture, navigation, components, content patterns, accessibility and localisation. |
| 723 | Website and Web Application Scaffold | Generate approved, maintainable web scaffolds with routing, configuration, tests and security defaults. |
| 724 | Mobile and Progressive Web Experience | Design mobile-first and PWA experiences with offline behaviour, permissions, updates and accessibility. |
| 725 | Form Workflow and Data Capture Builder | Build validated forms, consent, conditional logic, attachments, review, retention and error handling. |
| 726 | Content Management and Publishing Workflow | Manage content, roles, previews, approvals, scheduling, versioning, corrections and withdrawal. |
| 727 | Application Integration and API Composition | Compose approved APIs, events and connectors with schemas, identity, retries and observability. |
| 728 | Application Quality Security and Accessibility Testing | Test functionality, security, performance, accessibility, localisation and resilient behaviour. |
| 729 | Deployment Preview and Release Promotion | Promote immutable artefacts through preview, test and production gates with rollback evidence. |
| 730 | Application and Website Factory Assurance Gate | Gate applications on requirements, UX, security, integrations, tests, deployment and support. |
