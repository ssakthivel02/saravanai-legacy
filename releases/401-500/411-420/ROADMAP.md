# Releases 411–420 roadmap

    | Release | Capability | Intended outcome |
    |---:|---|---|
    | 411 | Sovereign AI Deployment Profile | Define jurisdiction, data boundary, model custody, key ownership, support and exit requirements. |
| 412 | Offline and Disconnected AI Runtime | Operate approved AI functions without network dependency using signed packages and bounded storage. |
| 413 | Edge Model Packaging and Verification | Package models with provenance, signatures, SBOM, compatibility, resource limits and revocation. |
| 414 | Device AI Policy and Posture | Bind device identity, posture, approved models, data classes, telemetry and quarantine controls. |
| 415 | Local Retrieval and Knowledge Synchronisation | Synchronise approved knowledge with integrity, deltas, retention, conflict and rollback controls. |
| 416 | Constrained Compute Optimisation | Govern quantisation, pruning, batching and acceleration through quality and safety evidence. |
| 417 | Offline Update and Patch Governance | Deliver signed updates through staged validation, expiry, rollback and emergency revocation. |
| 418 | Edge AI Privacy and Sensor Minimisation | Limit sensor data, retention, inference outputs and remote telemetry to the minimum necessary. |
| 419 | Sovereign Operations and Support Readiness | Define regional ownership, skills, spares, recovery, audit and support evidence. |
| 420 | Sovereign and Edge AI Assurance Gate | Gate sovereign and edge use on custody, integrity, privacy, support, recovery and exit evidence. |
