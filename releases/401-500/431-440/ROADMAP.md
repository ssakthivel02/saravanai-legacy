# Releases 431–440 roadmap

    | Release | Capability | Intended outcome |
    |---:|---|---|
    | 431 | Enterprise Lakehouse Domain Registry | Register governed data domains, products, owners, classifications, regions and lifecycle. |
| 432 | Data Ingestion and Change Data Capture | Govern sources, schemas, checkpoints, deduplication, lineage, replay and quarantine. |
| 433 | Batch and Stream Processing Governance | Version processing jobs, resources, quality gates, backfill, failure handling and rollback. |
| 434 | Data Quality Rules and Observability v2 | Operate rules, expectations, incidents, trends, owners and consumer impact evidence. |
| 435 | Data Lineage and Impact Analysis v2 | Track column, dataset, pipeline, model and report lineage with change-impact analysis. |
| 436 | Data Access Productisation | Publish governed datasets with contracts, scopes, purpose, approval, usage and revocation. |
| 437 | Data Retention Archival and Legal Hold | Apply retention, archival, deletion, legal holds, evidence and recovery controls. |
| 438 | Data Platform Cost and Capacity | Attribute storage and compute, forecast demand, enforce budgets and optimise free-first usage. |
| 439 | Data Platform Recovery and Portability | Test export, restore, schema portability, credential revocation and provider exit. |
| 440 | Governed Data Platform Assurance Gate | Gate data platform release on contracts, quality, lineage, access, retention and recovery evidence. |
