# Releases 441–450 roadmap

    | Release | Capability | Intended outcome |
    |---:|---|---|
    | 441 | Business Capability and Value Stream Map | Map capabilities, value streams, owners, outcomes, applications, data and dependencies. |
| 442 | Application Portfolio Rationalisation | Assess applications for value, risk, duplication, cost, lifecycle and target disposition. |
| 443 | ERP Integration and Transaction Governance | Govern transactions, idempotency, reconciliation, segregation, approvals and rollback. |
| 444 | CRM and Customer Data Integration | Integrate customer records with consent, matching, purpose, access and correction controls. |
| 445 | HR and Workforce System Integration | Integrate workforce systems with minimisation, role boundaries, fairness and legal review. |
| 446 | Finance and Procurement Integration | Govern purchase, invoice, budget, supplier and approval flows without enabling payments. |
| 447 | Enterprise Event and API Integration Hub | Operate events and APIs with schemas, ownership, security, replay, rate limits and observability. |
| 448 | Master Data and Reference Synchronisation v2 | Synchronise governed master data through stewardship, conflict, quality and rollback. |
| 449 | Business Transformation Benefits Tracking | Track outcomes, baselines, benefits, cost, dependencies, risks and accountable owners. |
| 450 | Business Architecture and Integration Gate | Gate transformation on capability, application, transaction, data and benefit evidence. |
