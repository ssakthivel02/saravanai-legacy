# Releases 421–430 roadmap

    | Release | Capability | Intended outcome |
    |---:|---|---|
    | 421 | Security Operations Case Management | Manage detections, incidents, evidence, assignments, containment, recovery and closure. |
| 422 | Threat Intelligence Source Governance | Register intelligence sources, licences, confidence, freshness, handling and revocation. |
| 423 | Detection Engineering Lifecycle | Version detection rules, tests, telemetry dependencies, tuning, ownership and retirement. |
| 424 | Security Analytics and Correlation | Correlate identity, endpoint, network, cloud and application signals with explainable evidence. |
| 425 | Automated Containment Safety | Execute approved containment with allowlists, bounded scope, dry-run, four-eyes and rollback. |
| 426 | Exposure and Vulnerability Prioritisation | Prioritise vulnerabilities through exploitability, asset criticality, exposure and compensating controls. |
| 427 | Identity Threat Detection and Response v2 | Detect compromised identities, risky sessions, privilege escalation and persistence patterns. |
| 428 | Cloud and SaaS Security Posture Operations | Assess configuration drift, public exposure, identity, data, logging and remediation ownership. |
| 429 | Cyber Threat Hunting Programme | Plan hypotheses, datasets, queries, findings, evidence, privacy and repeatability. |
| 430 | Security Operations Assurance Gate | Gate cyber operations on cases, intelligence, detections, containment, exposure and recovery evidence. |
