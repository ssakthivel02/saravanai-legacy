# Roadmap

| Release | Capability | Outcome |
|---:|---|---|
| 241 | Multi-Cloud Landing-Zone Governance | Define identity, network, logging and policy baselines. |
| 242 | Workload Placement and Portability | Select placement using data, latency, resilience, cost and exit constraints. |
| 243 | Hybrid Network and Connectivity Governance | Manage segmentation, routing, DNS, proxies and failover. |
| 244 | Edge Device and Fleet Operations | Govern device identity, posture, software and retirement. |
| 245 | Enterprise Backup and Data Protection | Require encryption, retention, immutability and restore tests. |
| 246 | FinOps Allocation and Budget Guardrails | Attribute cost, forecast and enforce hard stops. |
| 247 | Sustainability and Carbon-Aware Operations | Record energy estimates and methodology without unsupported claims. |
| 248 | Performance and Scalability Engineering | Validate throughput, latency, saturation and recovery. |
| 249 | Provider Neutrality and Exit Engineering | Maintain open formats, exports and tested exit procedures. |
| 250 | Multi-Cloud FinOps and Resilience Gate | Gate cloud placement on resilience, cost and exit evidence. |
