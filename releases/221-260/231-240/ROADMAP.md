# Roadmap

| Release | Capability | Outcome |
|---:|---|---|
| 231 | External Attack-Surface Management | Inventory public exposure, ownership and remediation. |
| 232 | Application Security Engineering | Apply threat modelling and security testing. |
| 233 | API and GraphQL Security | Enforce authentication, validation, rate limits and query controls. |
| 234 | Data Security Posture Management | Discover and remediate sensitive data exposure. |
| 235 | Secrets Certificates and Key Rotation | Govern rotation, expiry, revocation and emergency response. |
| 236 | Privacy Engineering and Data Protection by Design | Embed minimisation, retention, rights and sharing controls. |
| 237 | Identity Governance and Access Certification | Review roles, privileges, dormant access and separation. |
| 238 | Secure Software Development Lifecycle | Require SBOM, signing, reviews and vulnerability gates. |
| 239 | Security Metrics and Control Effectiveness | Measure evidence-backed control performance. |
| 240 | Security and Privacy Assurance Gate | Gate release on security, privacy and identity evidence. |
