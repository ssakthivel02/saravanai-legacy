# Programme roadmap

| Release | Capability | Outcome |
|---:|---|---|
| 221 | Enterprise Service Topology | Map services, dependencies, owners and critical paths. |
| 222 | Configuration and Asset Intelligence | Govern asset and configuration records with provenance and reconciliation. |
| 223 | Incident Intelligence and Triage | Correlate signals, severity, ownership and evidence. |
| 224 | Problem and Root-Cause Management | Track recurring failures, hypotheses, causes and corrective actions. |
| 225 | Change Risk Intelligence | Assess blast radius, tests, approvals and rollback. |
| 226 | Runbook and Remediation Orchestration | Execute bounded, approved and reversible runbooks. |
| 227 | Service-Level and Error-Budget Operations | Operate SLOs, error budgets and release consequences. |
| 228 | Operations Capacity and Demand Forecasting | Forecast demand, saturation and dependency constraints. |
| 229 | Operational Cost and Efficiency Management | Attribute cost and enforce free-first budget controls. |
| 230 | Enterprise Operations Assurance Gate | Gate operations on evidence and recovery readiness. |
| 231 | External Attack-Surface Management | Inventory public exposure, ownership and remediation. |
| 232 | Application Security Engineering | Apply threat modelling and security testing. |
| 233 | API and GraphQL Security | Enforce authentication, validation, rate limits and query controls. |
| 234 | Data Security Posture Management | Discover and remediate sensitive data exposure. |
| 235 | Secrets Certificates and Key Rotation | Govern rotation, expiry, revocation and emergency response. |
| 236 | Privacy Engineering and Data Protection by Design | Embed minimisation, retention, rights and sharing controls. |
| 237 | Identity Governance and Access Certification | Review roles, privileges, dormant access and separation. |
| 238 | Secure Software Development Lifecycle | Require SBOM, signing, reviews and vulnerability gates. |
| 239 | Security Metrics and Control Effectiveness | Measure evidence-backed control performance. |
| 240 | Security and Privacy Assurance Gate | Gate release on security, privacy and identity evidence. |
| 241 | Multi-Cloud Landing-Zone Governance | Define identity, network, logging and policy baselines. |
| 242 | Workload Placement and Portability | Select placement using data, latency, resilience, cost and exit constraints. |
| 243 | Hybrid Network and Connectivity Governance | Manage segmentation, routing, DNS, proxies and failover. |
| 244 | Edge Device and Fleet Operations | Govern device identity, posture, software and retirement. |
| 245 | Enterprise Backup and Data Protection | Require encryption, retention, immutability and restore tests. |
| 246 | FinOps Allocation and Budget Guardrails | Attribute cost, forecast and enforce hard stops. |
| 247 | Sustainability and Carbon-Aware Operations | Record energy estimates and methodology without unsupported claims. |
| 248 | Performance and Scalability Engineering | Validate throughput, latency, saturation and recovery. |
| 249 | Provider Neutrality and Exit Engineering | Maintain open formats, exports and tested exit procedures. |
| 250 | Multi-Cloud FinOps and Resilience Gate | Gate cloud placement on resilience, cost and exit evidence. |
| 251 | Enterprise Product Operating Model | Define ownership, outcomes, metrics and lifecycle. |
| 252 | Customer Insight and Feedback Governance | Collect consented feedback and protect personal data. |
| 253 | Experimentation and Product Decisioning | Run controlled experiments with stop rules and accountability. |
| 254 | AI Capability Catalogue and Marketplace | Publish governed AI capabilities with scopes and safety evidence. |
| 255 | Lifecycle Deprecation and Customer Migration | Manage notices, migration guides and support windows. |
| 256 | Legal Policy and Contract Readiness | Track terms, privacy, acceptable use and jurisdictional review. |
| 257 | Brand Trust and Public Communications | Govern claims, corrections, evidence and accessibility. |
| 258 | Operational Acceptance and Handover | Require ownership, monitoring, runbooks, backup and support. |
| 259 | Enterprise Release Readiness Board | Consolidate cross-domain launch evidence and residual risks. |
| 260 | Enterprise Operations and Product Completion Gate | Close the programme only after accountable approval. |
