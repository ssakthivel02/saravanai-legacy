# Runtime Wave 3 Low-Level Design

- `source-policy.js`: source type, URL, licence and date controls.
- `quarantine.js`: preview hashing and prompt-injection/secret markers.
- `retrieval.js`: query and source-tier planning without execution.
- `citations.js`: source ID, locator and quotation-length constraints.
- `contradictions.js`: candidate identification without truth adjudication.
- `temporal.js`: deterministic source-age thresholds.
- `evidence.js`: metadata hash and human-review requirement.
- `corrections.js`: allowlisted manual correction actions.
- `observability.js`: route and control posture without content.
