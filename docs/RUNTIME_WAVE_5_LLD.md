# Runtime Wave 5 Low-Level Design

- `slo.js`: objective validation and supplied-sample evaluation.
- `burn-rate.js`: multi-window error-budget burn classification.
- `incident.js`: deterministic SEV1–SEV4 triage.
- `change-risk.js`: evidence-based change scoring.
- `deployment.js`: non-executing deployment and rollback gates.
- `runbook.js`: allowlisted runbook selection.
- `health.js`: caller-supplied component aggregation.
- `alerting.js`: dashboard-only policy validation.
- `telemetry.js`: secret and email redaction.
- `evidence.js`: non-persistent decision metadata.
